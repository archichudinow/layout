Prompt Side Panel

A floating, draggable prompt box for ReImaginarium — The Tools. Layout only: it mirrors your text into the real prompt field and clicks Generate for you.

1 · Install

Drag this button onto your bookmarks bar (or right-click → Bookmark this link):

✦ Prompt Panel

Bookmarks bar hidden? Press Ctrl/⌘ + Shift + B to show it.

2 · Use

  1. Open the Tools page where your prompt field lives.
  2. Click the Prompt Panel bookmark.
  3. A floating column appears — drag it by its header, resize from the corner.
  4. Type in it; text flows into the real prompt field. Hit Generate or Ctrl/⌘ + Enter.
  5. Click the bookmark again (or ✕) to close it.

↻ pulls the current text from the page field into the panel. ⓘ writes a diagnostic report to the browser console. Position & size are remembered.

A strip at the bottom of the panel shows whether it is still wired to the page. The Tools app is updated from time to time, and when it renames the prompt field or the Generate button the panel says so there instead of failing silently.
